\begin{easyappendix}{Struktura repozytorium kodu i~instrukcja uruchomieniowa}
\label{app:kod}

Niniejszy załącznik zawiera techniczną dokumentację wytworzonego oprogramowania, opis struktury repozytorium oraz instrukcję reprodukcji wyników eksperymentów numerycznych i~optymalizacyjnych Bliźniaka Cyfrowego. Całość kodu źródłowego pracy została objęta systemem kontroli wersji Git i~jest dostępna w~repozytorium projektowym.

\section*{Wymagania środowiskowe i instalacja}

Projekt został zaimplementowany w~języku \textbf{Python~3.12} (z~pełną kompatybilnością z~wersjami 3.10--3.14). Zarządzanie zależnościami oparto o~środowisko wirtualne \texttt{venv} oraz zablokowane wersje bibliotek w~pliku \texttt{requirements.txt}.

\begin{lstlisting}[language=bash,
	caption={Kroki instalacji środowiska wirtualnego i~zależności},
	label={lst:instalacja}]
	# 1. Klonowanie repozytorium
	git clone https://github.com/rafal-kaczynski-raf-tech/praca-magisterska.git
	cd praca-magisterska

	# 2. Utworzenie i aktywacja wirtualnego srodowiska
	python3 -m venv .venv
	source .venv/bin/activate        # Linux / macOS
	# .venv\Scripts\activate         # Windows

	# 3. Instalacja scisle zdefiniowanych zaleznosci
	pip install --upgrade pip
	pip install -r requirements.txt
\end{lstlisting}

\section*{Główne zależności obliczeniowe i narzędziowe}
\begin{itemize}
	\item \textbf{NumPy} ($\ge 2.0.0$) -- wektoryzowane struktury danych, tablice próbek i~operacje całkowania trapezowego,
	\item \textbf{PySwarms} ($= 1.3.0$) -- zweryfikowana biblioteka akademicka kanonicznego algorytmu PSO (\texttt{GlobalBestPSO}),
	\item \textbf{SciPy} ($\ge 1.18.0$) -- funkcje statystyczne i~pomocnicze procedury naukowe,
	\item \textbf{Matplotlib} ($\ge 3.10.0$) -- generowanie publikacyjnych wykresów i~trajektorii czasowych,
	\item \textbf{ReportLab} ($\ge 4.0.0$) -- automatyczny generator formalnych raportów akademickich w~formacie PDF.
\end{itemize}

\section*{Struktura katalogów i modułów projektu}
Wspólny kod projektu oddzielono od~skryptów eksperymentalnych. Katalogi pod \directory{kroki/} są~ponumerowane zgodnie z~kolejnością prac; przechowują skrypty, dane wejściowe oraz dostępne wyniki danego etapu.

\begin{itemize}
	\item \directory{src/} -- Rdzeń Bliźniaka Cyfrowego (silnik fizyczny i~sterowniki):
	\begin{itemize}
		\item \texttt{converter.py} -- model stanu przekształtnika podwyższającego (Boost) i~implementacja metody Eulera,
		\item \texttt{controller.py} -- implementacja regulatorów: histerezowego, klasycznego MF-BB oraz proponowanego Trend MF-BB z~ogranicznikiem prądu,
		\item \texttt{simulator.py} -- orkiestrator pętli czasowej sprzęgający fizykę obwodu z~dyskretnym taktowaniem sterownika,
		\item \texttt{filters.py} -- dyskretne filtry dolnoprzepustowe 1. rzędu Tustina ($T_s = 10~\mu\mathrm{s}$),
		\item \texttt{config.py} -- klasy konfiguracyjne parametrów obwodu i~symulacji oparte o~dekorator \texttt{@dataclass}.
	\end{itemize}
	\item \directory{optymalizacja/} -- współdzielone moduły optymalizacji i~analizy:
	\begin{itemize}
		\item \texttt{pyswarms\_optimizer.py} -- adapter łączący symulator z~biblioteką \texttt{PySwarms},
				\item \texttt{cost\_functions.py}, \texttt{metrics.py} i~\texttt{scenarios.py} -- współdzielone definicje funkcji celu, metryk oraz scenariuszy,
				\item \texttt{test\_pyswarms\_porownanie.py} -- porównanie wyników optymalizacji PySwarms z~procedurą referencyjną.
	\end{itemize}
	\item \directory{kroki/} -- archiwum kolejnych etapów badań:
	\begin{itemize}
		\item \texttt{01\_silnik\_fizyczny/}--\texttt{05\_walidacja\_silnika\_i\_replay/} -- model, sterownik MF-BB i~jego walidacja względem PSIM,
		\item \texttt{06\_pso\_i\_funkcje\_celu/}--\texttt{08\_scenariusz\_dynamiczny/} -- strojenie PSO, warianty funkcji celu i~scenariusze dynamiczne,
		\item \texttt{09\_trend\_mf\_bb/}--\texttt{11\_optymalizacja\_dwuetapowa/} -- regulator Trend MF-BB, porównania częstotliwości i~optymalizacja dwuetapowa,
		\item \texttt{12\_badanie\_wrazliwosci/}--\texttt{14\_replay\_koncowy/} -- badania wrażliwości, wpływu pojemności i~końcowy replay.
	\end{itemize}
	\item \directory{tests/} -- test regresyjny \texttt{test\_regression.py}, skrypt tworzący baseline oraz zamrożone dane \texttt{baseline\_results.npz}.
	\item \texttt{README.md} -- indeks katalogów \texttt{kroki/} i~instrukcja uruchomienia projektu.
\end{itemize}

\section*{Instrukcja uruchomienia kluczowych eksperymentów}

\begin{lstlisting}[language=bash,
	caption={Polecenia uruchomienia testow, symulacji oraz optymalizacji},
	label={lst:uruchomienie}]
	# Polecenia wykonuj z katalogu glownego repozytorium
	# 1. Test regresyjny porownujacy wyniki z baseline'em
	python tests/test_regression.py

	# 2. Porownanie symulacji z pelnym przebiegiem PSIM
	PYTHONPATH=. python kroki/04_estymacja_pradu_i_walidacja/porownanie_bb_estim_full_psim.py

	# 3. Dwutorowa optymalizacja 2D
	PYTHONPATH=. python kroki/11_optymalizacja_dwuetapowa/optymalizacja_dwuetapowa_2d.py

	# 4. Badanie wrazliwosci algorytmu PSO
	PYTHONPATH=. python kroki/12_badanie_wrazliwosci/badanie_wrazliwosci.py
\end{lstlisting}

Wspólne moduły pozostają w~katalogach \directory{src/} i~\directory{optymalizacja/}. Skrypty oraz zarchiwizowane dane, wykresy i~raporty eksperymentów są pogrupowane w~odpowiadających im katalogach \directory{kroki/}. Docelowe miejsce zapisu nowych plików określają ścieżki zdefiniowane w~poszczególnych skryptach.
